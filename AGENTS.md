# Agent instructions — Spyderwell websites

Read docs/WEB-STANDARDS.md and README.md before editing. Google's Modern Web Guidance is a reference, not permission to rewrite the site.

- Inspect existing structure and Netlify configuration before proposing changes; distinguish verified facts from assumptions.
- Preserve visual identity, routes, copy and functionality unless change is approved. Keep dependencies minimal.
- Write readable semantic HTML, maintainable CSS and accessible JavaScript. Do not minify checked-in source.
- Explain non-obvious changes in the PR and update relevant documentation.
- Do not commit secrets, tokens, personal data or credentials. Do not assume client-side hiding protects private content.
- Validate with appropriate checks and report which checks were not run.
- Never merge to main, publish, schedule or deploy without explicit authorization.
